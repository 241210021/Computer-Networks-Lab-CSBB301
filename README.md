## 🚀 Quick Start

1. Open the folder for the experiment you want.
2. Read the **aim** and **theory** first.
3. Recreate the topology in Packet Tracer (for the simulation experiments).
4. Apply the listed configuration commands.
5. Test with `ping` and compare against the recorded observations.
